# AI Reflection

AI support was helpful in speeding up implementation ideas, validation logic, wording, and documentation structure for this project. It was especially useful for identifying missing flows such as borrowed-book visibility in the user profile, better onboarding content, and stronger validation around email format, duplicate titles, and return dates.

At the same time, this project still required manual review. The final codebase had to be checked against the intended behavior, and the documentation needed to be rewritten so it matched the actual file structure and route flow instead of generic boilerplate. That review step was important because AI suggestions can be directionally useful while still needing cleanup, correction, or narrowing.

The main lesson from using AI here is that it works best as a collaborator, not a replacement for project understanding. It helped move faster, but accuracy still depended on manually connecting the frontend, backend, and database behavior into one coherent application story.
